# 定义
---
>[!note] 寻址方式
>寻址方式决定了如何根据指令中的地址码找到操作数的物理地址（有效地址，Effective Address）。

| 寻址方式    | 有效地址                                       |     |
| ------- | ------------------------------------------ | --- |
| 立即寻址    | 操作数就在指令中                                   |     |
| 直接寻址    | $EA = A$                                   |     |
| 间接寻址    | $EA = (A)$                                 |     |
| 寄存器寻址   | $EA = R_{i}$                               |     |
| 寄存器间接寻址 | $EA = (R_{i})$                             |     |
| 基址寻址    | $EA = R_{b} + D$                           |     |
| 变址寻址    | $EA = R_{x} + A$                           |     |
| 相对寻址    | $EA = (PC) + D$                            |     |
| 页面寻址    | Z/C=0时：$EA = A$；Z/C=1时：$EA = (PC)_{H} + A$ |     |
