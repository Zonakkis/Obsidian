# 基础概念
## 度
**树的度**：树上所有节点的度的最大值
**节点的度**：节点拥有的子树数量
# 树的遍历
树的遍历是指按照某种顺序访问树中所有节点的操作。
## 深度优先遍历（Depth First Search）
### 先序遍历（Preorder Traversal）
访问顺序：根节点 → 左子树 → 右子树
例：
![先序遍历](https://oi-wiki.org/graph/images/tree-basic-preorder.svg)
### 中序遍历（Inorder Traversal）（仅适用于**二叉树**）
访问顺序：左子树 → 根节点 → 右子树
例：
![先序遍历](https://oi-wiki.org/graph/images/tree-basic-inorder.svg)
### 后序遍历（Postorder Traversal）
访问顺序：左子树 → 右子树 → 根节点
