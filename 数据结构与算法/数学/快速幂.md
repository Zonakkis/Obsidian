# 定义
快速幂是一种计算a<sup>n</sup>时，将n表示成2进制进行计算，减少乘法次数的快速计算幂的方法。时间复杂度为*O(logn)*。
例： 3<sup>13</sup> = 3<sup>1101</sup>=3<sup>8</sup>3<sup>4</sup>3<sup>1</sup>。

### 不取模
```c++
int fast_pow(int a,int b)
{
	int result = 1;
	while(b > 0)
	{
		if(b & 1)
			result *= a;
		a *= a;
		b >>= 1;
	}
	return result;
}
```
### 取模
```c++
const int MOD = 9901;
int fast_pow(int a,int b)
{
	a %= MOD;
	int result = 1;
	while(b > 0)
	{
		if(b & 1)
			result = result * a % MOD;
		a = a * a % MOD;
		b >>= 1;
	}
	return result;
}
```
