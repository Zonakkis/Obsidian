# 特点
---
- **平台无关性**：一次编译，到处运行。Java编译器将源代码编译为字节码(bytecode)，只要系统安装了Java虚拟机(JVM)就能够运行。
- **面向对象**：Java是严格面向对象的编程语言。[[面向对象编程|面向对象]]的类和对象以及继承、多态、封装等特性使得代码更易于维护和重用。
- **内存管理**：Java有垃圾回收器，自动管理内存并回收不再使用的对象。开发者不需要手动管理对象，减少了内存泄漏和其他内存相关的问题。
# 优点和缺点
---
**优点**：
 - **跨平台**
 - **面向对象**
 - **生态强大**：Spring
 - **支持多线程**：方便并发编程
 **缺点**：
 - **性能**：相比于C++等原生编译语言仍有一定差距。
 - **内存消耗**：JVM本身需要占用一定内存
