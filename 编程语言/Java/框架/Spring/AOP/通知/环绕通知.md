# 定义
>[!note] 环绕通知
>手动控制[[连接点]]的运行，使用[[@Around]]指定[[切入点]]和通知方法。通知方法的返回值将代替[[连接点]]的返回值。
# 参数
## ProceedingJoinPoint
必须有一个类型为[[ProceedingJoinPoint]]的参数来执行[[连接点]]（方法）。
# 示例
```java
@Aspect  
@Component
@Slf4j
public class LogAspect {
	@PointCut("@annotation(com.example.annotation.Log)")
	public void logAnnotation() { }
	
	@Around("logAnnotation()")
	public void logAround(ProceedingJoinPoint proceedingJoinPoint) {  
		MethodSignature signature = (MethodSignature) proceedingJoinPoint.getSignature();  
		Method method = signature.getMethod();
		log.info(“before method:{}”, method.getName());
		proceedingJoinPoint.proceed();
		log.info(“after method:{}”, method.getName());
	}
}
```
