# 相关公式
---
1. **周转时间** = 完成时间 - 到达时间
2. **平均周转时间** = 各进程周转时间之和 / 进程数
3. **带权周转时间** = 周转时间 / 实际运行服务时间
4. **等待时间** = 周转时间 - 实际运行服务时间
5. **响应时间** = 首次被CPU执行时间 
# 调度算法
---
## 先来先服务算法（FCFS）
按照作业到达的先后次序进行调度。
**优点**：算法简单，对长作业有利。
**缺点**：对短作业非常不利。
## 短作业优先算法（SJF）
作业的运行时间越短，优先级越高。
**优点**：平均等待时间和平均周转时间最短。
**缺点**：对长作业非常不利，可能导致饥饿。
## 优先级调度算法（PSA）
每个进程都有一个优先级，优先级高的先进行调度。
## 高响应比优先调度算法
$$响应比 = \frac{等待时间 + 要求服务时间}{要求服务时间} = \frac{响应时间}{要求服务时间}$$
当等待时间相同时，要求服务时间越短，响应比越高（类似于SJF）。
当要求服务时间相同时，等待时间越长，响应比越高（类似于FCFS）。
对于长作业，随着等待时间的增加响应比逐渐提高，最后也能获得处理机。
