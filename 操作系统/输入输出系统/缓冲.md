# 缓冲区
---
## 单缓冲区
![[单缓冲区.png]]
CPU处理数据和将数据从硬盘输入到缓冲区可以同时进行。
T：将一块数据从硬盘输入到缓冲区的时间
M：将数据从缓冲区传送到工作区的事件
C：CPU处理数据的时间
N：数据块的个数
其中有N-1个T和C重叠
因此$总时间 = T + N * M + (N - 1) * max(T, C) + C = (N - 1) * max(T, C) + N * M + T + C$
## 双缓冲区
![[双缓冲区.png]]
将数据从硬盘输入到将数据从缓冲区传送到工作区的事件缓冲区+CPU处理数据和可以同时进行。
T：将一块数据从硬盘输入到缓冲区的时间
M：将数据从缓冲区传送到工作区的事件
C：CPU处理数据的时间
N：数据块的个数
其中有N-1个T和M+C重叠
因此$总时间 = T + (N - 1) * max(T, M + C) + M + C = (N - 1) * max(T, M + C) + T + M + C$
