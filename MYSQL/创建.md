# 创建数据库
## create database
创建一个新的数据库。
```sql
create database <database_name>;
```
`<database_name>`：要创建的数据库的名字。
例：
```sql
create database database_example;
```
# 创建表
## create table
创建一张新的表。
```sql
create table <table_name> ( <columns> <datatypes> );
```
`<table_name>`：要创建的表的名字。
`<columns>`：表含有的字段名称。
`<datatypes>`：字段的数据类型。
例：
```sql
create table user ( id int, name varchar(10), age int );
```
# 创建字段
## alter table add column
向现有表中添加新的字段。
```sql
alter table <talbe_name> 
	add column <column_name>;
```
`<table_name>`：要添加字段的表的名字。
`<column_name>`：要添加的字段名字。
