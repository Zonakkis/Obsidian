# 定义
这种把多条语句作为一个整体进行操作的功能，被称为数据库事务。数据库事务可以确保该事务范围内的所有操作都可以全部成功或者全部失败。如果事务失败，那么效果就和没有执行这些SQL一样，不会对数据库数据有任何改动。
# 特性
事务有四大特性：原子性，一致性，隔离性，持久性（即ACID）。
- 原子性（Atomicity）：一个事务中的所有操作，要么全部执行，要么全部不执行。如果在执行过程中发生错误，会被回滚到事务开始前的状态。
- 一致性（Consistency）：事务执行前后，数据库保持一致状态，完整性没有被破坏。
- 隔离性（Isolation）：并发事务之间相互独立，不会互相干扰而导致出现数据不一致的问题。
- 持久性（Durability）：事务执行后，数据的修改将被永久保存。
