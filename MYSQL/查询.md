# select from 
从数据库中选取需要查询的数据。
```sql
select * from <tables>
select <columns> from <tables>;
```
`*`:通配符，表示选择表中所有的字段。
`<columns>`：要选择的字段名称。
`<tables>`：要查询的表名称。
例：
```sql
select * from user;
select id,name from user;
```
## distinct：去重
去除查询结果中重复的记录。
```sql
select distinct <columns> from <tables>;
```
`<columns>`：要查询的字段名称。（使用通配符`*`时，表示选择表中所有的字段。）
`<tables>`：要查询的表名称。
例：
```sql
select id,name from user;
select distinct id,name from user;
```

| 结果1： | id  | name | 结果2： | id  | name |
| ---- | --- | ---- | ---- | --- | ---- |
|      | 1   | 张三   |      | 1   | 张三   |
|      | 2   | 张三   |      | 2   | 张三   |
|      | 2   | 张三   |      | 3   | 李四   |
|      | 3   | 李四   |      |     |      |
## where：筛选
查询时筛选符合条件的数据。
```sql
select <columns> from <tables> where <conditions>;
```
`<columns>`：要查询的字段名称。（使用通配符`*`时，表示选择表中所有的字段。）
`<tables>`：要查询的表名称。
`<conditions>`：筛选条件。
筛选运算符：

| =   | <>  | >   | <   | >=   | <=   | between and | like | in       |
| --- | --- | --- | --- | ---- | ---- | ----------- | ---- | -------- |
| 等于  | 不等于 | 大于  | 小于  | 大于等于 | 小于等于 | 在范围内        | 模式搜索 | 匹配多个可能的值 |
条件连接运算符：

| and | or  | not |
| --- | --- | --- |
| 和   | 或   | 否   |
例：
```sql
select name from user where id = 1 and age >= 18;
```
## order by：排序
对查询结果进行排序。
```sql
select <columns> from <tables> order by <columns> [ASC|DESC];
```
`<columns>`：要查询的字段名称。（使用通配符`*`时，表示选择表中所有的字段。）
`<tables>`：要查询的表名称。
`<columns>`：要进行排序的字段名称。（有多个字段时，按照顺序进行排列，即先比较第一个字段，第一个字段相同时比较第二个字段，以此类推。）
ASC：升序排列。
DESC：降序排列。
例：
```sql
select name from user order by age DESC, id ASC;
```
## count：计数
计算查询结果中行的数量。
```sql
select count(<columns>) from <tables>;
```
`<columns>`：要查询的字段名称。（使用通配符`*`时，表示选择表中所有的字段。）
`<tables>`：要查询的表名称。
