# 删除数据库
## drop
删除一个数据库。
```sql
drop database <database_name>;
```
`<database_name>`：要删除的数据库名称。
例：
```sql
drop database databaseExample;
```
# 删除表
## drop
删除数据库中的一张表。
```sql
drop table <table_name>;
```
`<table_name>`：要删除的表名称。
例：
```sql
drop table user;
```

# 删除记录
## delete
删除表中的一条记录。
```sql
delete from <table_name> where <conditions>;
```
`<table_name>`：要删除纪录的表名称。
`<conditions>`：筛选条件。
例：
```sql
delete from user where name = '张三';
```
