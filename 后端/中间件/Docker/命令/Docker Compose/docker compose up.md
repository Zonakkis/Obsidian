# 定义
---
>[!note] docker compose up
>创建并启动容器
>格式：docker compose up [OPTIONS] [SERVICE...]

# 参数
---

| 选项                  | 用法              | 描述                  |
| ------------------- | --------------- | ------------------- |
| `-d, --detach`      | `-d`            | 在后台运行               |
| `-p、--project-name` | `-p my-project` | 设置项目名称（`-p`要放在up之前） |
