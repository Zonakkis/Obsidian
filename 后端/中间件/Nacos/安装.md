# Docker
---
使用MySQL作为数据库。
拉取镜像：`docker pull nacos/nacos-server:latest`。
MySQL创建一个表并导入Schema：[Github](https://raw.githubusercontent.com/alibaba/nacos/refs/heads/develop/plugin-default-impl/nacos-default-datasource-plugin/nacos-datasource-plugin-mysql/src/main/resources/META-INF/mysql-schema.sql)。
创建并运行容器：
```bash
docker run --name nacos \
    -e PREFER_HOST_MODE=hostname
	-e MODE=standalone
	-e NACOS_AUTH_TOKEN=mgzxi/fYDLXoVSSESmctIMOaDocg00f3cd8Fgul8Gv4=
	-e NACOS_AUTH_IDENTITY_KEY=serverIdentity
	-e NACOS_AUTH_IDENTITY_VALUE=security
	-e SPRING_DATASOURCE_PLATFORM=mysql
	-e MYSQL_SERVICE_HOST=mysql
	-e MYSQL_SERVICE_DB_NAME=nacos
	-e MYSQL_SERVICE_PORT=3306
	-e MYSQL_SERVICE_USER=root
	-e MYSQL_SERVICE_PASSWORD=zonakkis
	-e MYSQL_SERVICE_DB_PARAM=characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
    -p 8080:8080 \
    -p 8848:8848 \
    -p 9848:9848 \
    -d nacos/nacos-server:latest
```
