# 架构
---

| 区域       | 共享性  |
| -------- | ---- |
| 程序计数器    | 线程私有 |
| Java虚拟机栈 | 线程私有 |
| 本地方法栈    | 线程私有 |
| Java堆    | 线程共享 |
| 方法区      | 线程共享 |
# 程序计数器
---
程序计数器是一块内存较小的空间，记录当前线程下一条字节码指令地址。执行本地方法时，程序计数器的值为空（Undefined）。
程序计数器是唯一没有OutOfMemoryError (OOM)的区域，因为大小是固定的。
# Java虚拟机栈
---
Java 虚拟机栈描述的是Java方法执行的内存模型。
栈的单位是**栈帧**：每个方法执行时都会创建一个栈帧，从方法调用到执行完毕对应着栈帧入栈到出栈的过程。
**栈帧的结构**：
1. **局部变量表**：存放方法参数和方法内定义的局部变量（包括基本数据类型、对象引用和returnAddress等）。最小单位是变量槽。
2. **操作数栈**：后进先出栈，方法的执行计算过程中的临时数据存储区。
3. **动态链接**：栈帧保存了当前方法所属类的运行时常量池引用，用于支持动态链接。
4. **方法返回地址**：方法执行完毕退出后：
	1. 正常返回：有返回值则把返回值压入调用者的操作数栈，将PC恢复为调用者执行该方法调用指令时PC的值，继续执行下一条指令。
	2. 异常返回：通过异常处理器进行匹配和查找返回地址，没有找到就向上传播，最终仍未处理则导致线程
**相关参数配置**：
- `-Xss`：设置每个线程的栈内存大小。例：`-Xss1m`。
# 本地方法栈
---
与Java虚拟机栈类似，但本地方法栈描述的是本地方法执行的内存模型。
# Java堆
---
JVM中最大的一块内存区域，在JVM启动时创建，用于存放对象实例。几乎所有的对象实例以及数组都在这里分配内存。
**相关参数配置**：
- `-Xms`：初始堆大小。例：`-Xss1g`。
# 方法区
---
方法区是JVM的**规范**，用于存储已经被虚拟机加载的类型信息、常量、静态变量、JIT编译后的代码缓存等。永久代和元空间是方法区的两种不同**实现**。
## 永久代（PermGen）
JDK7以及之前，HotSpot使用Java堆的内存的一部分作为方法区，内存受限于JVM内存大小。
## 元空间（Metaspace）
JDK8以及之后，彻底移除了永久代，改用元空间实现。
元空间不在虚拟机内存中，而是直接使用直接内存，内存只受限于系统物理内存。
## 运行时常量池
方法区的一部分。JVM加载一个类后会将Class文件中的常量池加载到运行时常量池中。
