# 程序计数器
---
程序计数器是一块内存较小的空间，记录当前线程下一条字节码指令地址。
程序计数器是唯一没有OutOfMemoryError (OOM)的区域，因为大小是固定的。
# Java 虚拟机栈
---
Java 虚拟机栈描述的是Java方法执行的内存模型。
栈的单位是**栈帧**：每个方法执行时都会创建一个栈帧，从方法调用到执行完毕对应着栈帧入栈到出栈的过程。
**栈帧的结构**：
1. **局部变量表**：存放方法参数和方法内定义的局部变量（包括基本数据类型、对象引用和returnAddress等）。最小单位是变量槽。
2. **操作数栈**：后进先出栈，方法的执行计算过程中的临时数据存储区。
3. **动态链接**：栈帧保存了当前方法所属类的运行时常量池引用，用于支持动态链接。
4. **方法返回地址**：方法执行完毕退出后：
	1. 正常返回：有返回值则把返回值压入调用者的操作数栈，将PC恢复为调用者执行该方法调用指令时PC的值。
	2. 异常返回：通过查询异常处理表进行匹配和查找返回地址。
