# 配置
---
在配置类中注册`MybatisPlusInterceptor`为bean并将`PaginationInnerInterceptor`添加到`MybatisPlusInterceptor`中。
```java
@Configuration
@MapperScan("scan.your.mapper.package")
public class MybatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 如果配置多个插件, 切记分页最后添加
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL)); 
        // 如果有多数据源可以不配具体类型, 否则都建议配上具体的 DbType
        return interceptor;
    }
}
```

## 在Serivce中使用
`IService<T>`接口中定义了以下方法：
`<E extends IPage<T>> E page(E page)`
`<E extends IPage<T>> E page(E page, Wrapper<T> queryWrapper)`
定义`Page<T>`查询对象并使用该方法即可进行分页查询。
```java
@RestController  
@RequestMapping("/user")  
public class UserController {  
  
    @Autowired  
    private IUserService userService;

    public void pageQuery(@RequestParam("page") int page) {
```
