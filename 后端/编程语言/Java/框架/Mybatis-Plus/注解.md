# @TableName
---
实体类名与数据库表名约定：实体类名（大驼峰命名法）、数据库表名（蛇形命名法）。
不符合时使用：
```java
@TableName("tb_user")
public class User {
	private Long id;
	private String name;
}
```

| 属性    | 类型     | 默认值 |       |
| ----- | ------ | --- | ----- |
| value | String |     | 数据库表名 |
# @TableId
---
标记实体类中的主键字段，以及指定主键的生成策略。
约定实体类中名为id的字段作为主键。
不符合时使用：
```java
public class User {
	@TableId
	private Long id;
	private String name;
}
```

| 属性    | 类型     | 默认值         |                                                                                                                                                                                                                                                                                                                                                       |
| ----- | ------ | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| value | String |             | 数据库表的主键字段名。不设置时将使用使用了@TableId的字段名。                                                                                                                                                                                                                                                                                                                    |
| type  | Enum   | IdType.NONE | **IdType 枚举类型定义**<br>`IdType.AUTO`：使用数据库自增 ID 作为主键。<br>`IdType.NONE`：使用全局配置中配置的IdType类型。<br>`IdType.INPUT`：在插入数据前，由用户自行设置主键值。<br>`IdType.ASSIGN_ID`：自动分配 `ID`，适用于 `Long`、`Integer`、`String` 类型的主键。默认使用雪花算法通过 `IdentifierGenerator` 的 `nextId` 实现。<br>`IdType.ASSIGN_UUID`：自动分配 `UUID`，适用于 `String` 类型的主键。默认实现为 `IdentifierGenerator` 的 `nextUUID` 方法。 |
# @TableField
---
实体类字段名与数据库表字段名约定：实体类字段名（小驼峰命名法）、数据库表字段名（蛇形命名法）
不符合时使用：
```java
public class User {
	private Long id;
	@TableField("username")
	private String name;
}
```

| 属性    | 类型      | 默认值  |           |
| ----- | ------- | ---- | --------- |
| value | String  |      | 数据库表的字段名  |
| exist | boolean | true | 是否为数据库表字段 |
