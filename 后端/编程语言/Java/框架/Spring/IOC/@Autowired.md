# 定义
---
>[!note] @Autowired
>@Autowired是Spring提供的用于依赖注入注解，用于标记需要自动注入的对象。

---

|     | 属性注入 | 构造器注入              | Setter注入 |
| --- | ---- | ------------------ | -------- |
| 优点  | 代码简洁 | 依赖不可变(final)、避免NPE |          |
| 缺点  |      |                    |          |
|     |      |                    |          |
