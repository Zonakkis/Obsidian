# 定义
>[!note] 后置返回通知
>在[[连接点]]执行成功之后执行通知，使用[[@AfterReturning]]指定切入点和通知方法。
# 参数
## JoinPoint
在需要[[连接点]]（方法）的信息时，可以为通知添加一个[[JoinPoint]]类型的参数来获取。
>[!tip] 参数位置
>在Spring中，建议将`JoinPoint`作为第一个参数。
## 返回值
在需要返回值时，为通知添加一个返回值类型的参数并将[[@AfterReturning]]的[[@AfterReturning#returning||returning]]赋值为参数名。
# 示例

```java
@Aspect  
@Component
@Slf4j
public class LogAspect {
	@PointCut("@annotation(com.example.annotation.Log)")
	public void logAnnotation() { }
	
	@AfterReturning(pointcut = "logAnnotation()", returning = "returnValue")
	public void logAfterReturning(JoinPoint joinPoint,Object returnValue) {  
		MethodSignature signature = (MethodSignature) joinPoint.getSignature();  
		Method method = signature.getMethod();
		log.info(“after method:{} successed with:{}”, method.getName(), returnValue);
	}
}
```
