# 添加依赖
---
pom.xml：
```xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>
```
# 配置
---
application.yml：
```yaml
spring:  
  application:  
    name: user-service # 服务名
  cloud:
	nacos:
	  server-addr: localhost:8848 # nacos服务端地址
    
```
