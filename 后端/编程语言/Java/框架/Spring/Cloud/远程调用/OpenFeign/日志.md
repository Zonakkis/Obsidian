OpenFeign有四种日志级别：
- `NONE`：默认值，不记录任何日志。
- `BASIC`：仅记录请求方法、URL、响应状态码及执行耗时。
- `HEADERS`：包含 BASIC 的内容，额外增加请求头和响应头信息。
- `FULL`：记录完整的请求与响应 Header、Body（正文）及元数据。
默认级别为`NONE`。
# 配置文件
---
在`application.yml`中：
```yaml
feign:  
  client:  
    config: 
      # 全局生效
      default:  
        logger-level: full
      # 局部生效：
      user-service: # 调用的微服务名称或 @FeignClient的name 
        logger-level: full
```
