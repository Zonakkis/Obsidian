# 容器
---
容器是一个软件的独立进程。
特点：
- **自包含**：包含其依赖的所有环境，不依赖主机上的任何依赖项。
- **隔离性**：容器运行在隔离环境中，对主机和其他容器几乎没有影响。
- **独立性**：每个容器都独立管理，删除一个容器不会影响其他容器。
- **便携性**：容器可以在任何地方运行。
- **易失性**：当容器被删除时，容器的文件变化
# 镜像
---
镜像是一个标准化的软件包，包含了运行容器所需的所有文件、二进制文件、库和配置。
特点：
- **不可变性**：镜像一旦创建，就不能被修改，要对其进行修改，只能创建新的镜像。
- **分层**：镜像由多层组成，每一层代表一组文件系统的变化。
# 镜像仓库
---
镜像仓库是用于存储和共享容器镜像的集中位置。它可以是公共的，也可以是私有的。
[Docker Hub](https://hub.docker.com/) 是默认的公共镜像仓库。
# Docker守护进程
---
Docker 守护进程（ `dockerd` ）监听 Docker API 请求并管理 Docker 对象。
