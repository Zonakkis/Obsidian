|           | Markdown                                                  | 预览效果                          |
| --------- | --------------------------------------------------------- | ----------------------------- |
| 链接 (Link) | `[显示名](http://example.com)`                               | [显示名](http://example.com)     |
| 粗体链接      | `**[显示名](http://example.com)**`                           | **[显示名](http://example.com)** |
| 斜体链接      | `*[显示名](http://example.com)* 或 [显示名](http://example.com)` | _[显示名](http://example.com)_   |
| 代码链接      | ``[`显示名`](http://example.com)``                           | [`显示名`](http://example.com)   |
^example
